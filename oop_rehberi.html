1. Neden OOP? Düz Fonksiyonlar ve Sözlükler Neden Yetmedi?

Eğitimin ilk günlerinde ürünlerimizi sıradan Python sözlükleri (dict) olarak tutmuştuk:

# Eski Yöntem (Düz Sözlük):
urun_1 = {"id": 1, "isim": "Kulaklık", "fiyat": 1500}
urun_2 = {"id": 2, "name": "Klavye", "ucret": 2200}  # DİKKAT: Anahtar isimleri karıştı!
⚠️ Buradaki 3 Büyük Problem:
  1. İsim Garantisi Yok: Bir yerde "fiyat", başka bir dosyada "ucret" yazabilirsiniz. Python bunu derleme anında fark edemez ve sistem patlar.
  2. Veri Tipi Kontrolü Yok: Biri fiyat: "bin lira" yazarsa sözlük bunu sessizce kabul eder.
  3. Veri ile Davranış Birbirinden Kopuk: Fiyata KDV eklemek isterseniz, dosyanın başka bir köşesine def kdv_ekle(fiyat) fonksiyonu yazmanız gerekir. Veri bir yerde, onu işleyen kod başka yerdedir.
💡 Çözüm: Veriyi (özellikleri) ve o veriyi işleyen fonksiyonları (davranışları) tek bir şablon çatısı altında toplamak. İşte buna OOP (Nesne Yönelimli Programlama) diyoruz!

2. Sınıf (Class) ve Nesne (Object) Nedir?

Bu iki kavramı anlamanın en meşhur yolu Kek Kalıbı ve Pişen Kek benzetmesidir:

  • Sınıf (Class): Kek kalıbıdır, mimari plandır, fabrikadaki kalıptır. Tek başına hafızada yer tutmaz; sadece ürünün nasıl üretileceğinin kuralını belirler.
  • Nesne (Object / Instance): O kalıptan fırından çıkan gerçek kektir, fabrikadan çıkan gerçek arabadır.
Kalıptan Nesne Üretim Şeması
class Urun (Kalıp)
➔
Nesne 1: Kulaklık (1500 TL)
Nesne 2: Klavye (2200 TL)
Nesne 3: Mouse (800 TL)
# 1. KALIP (Class) Tanımlıyoruz:
class Urun:
    isim: str
    fiyat: int

# 2. KALIPTAN NESNE (Object) Üretiyoruz:
u1 = Urun()
u1.isim = "Kulaklık"
u1.fiyat = 1500

u2 = Urun()
u2.isim = "Klavye"
u2.fiyat = 2200

Artık u1 ve u2, Urun sınıfından üretilmiş iki bağımsız nesnedir. Biri değiştiğinde diğeri asla etkilenmez.

3. "self" Ne Demektir? Neden Her Yere Yazıyoruz?

Python'da sınıflara ilk adım atıldığında en kafa karıştırıcı kelime self kelimesidir.

🧠 Günlük Hayat Karşılığı: Türkçedeki "Kendi" veya "Benim" zamiridir.

Bir sınıfa metot (fonksiyon) yazdığınızda, o metodun hangi nesne için çalıştığını bilmesi gerekir:

  • "Kulaklık'ın fiyatı" mı, yoksa "Klavye'nin fiyatı" mı?

İşte self, o an hangi nesne üzerinde işlem yapılıyorsa onu temsil eder.

class Urun:
    def __init__(self, isim: str, fiyat: int):
        self.isim = isim    # "Bu nesnenin kendi ismi, dışarıdan gelen isim olsun"
        self.fiyat = fiyat  # "Bu nesnenin kendi fiyatı, dışarıdan gelen fiyat olsun"

    def bilgileri_yazdir(self):
        # self.isim diyerek "hangi ürün çağrıldıysa onun ismini yaz" diyoruz
        print(f"Ürün: {self.isim}, Fiyat: {self.fiyat} TL")

# Kullanım:
kulaklik = Urun("Kablosuz Kulaklık", 1500)
klavye = Urun("Mekanik Klavye", 2200)

kulaklik.bilgileri_yazdir()  # self = kulaklik -> "Ürün: Kablosuz Kulaklık"
klavye.bilgileri_yazdir()    # self = klavye   -> "Ürün: Mekanik Klavye"

4. __init__ (Kurucu Metot) Nedir?

__init__, İngilizce "initialize" (başlatmak / ilk ayarlarını yapmak) kelimesinden gelir.

Bir nesne dünyaya geldiği (oluşturulduğu) ilk saniyede otomatik olarak çalışan özel bir fonksiyondur.

class Urun:
    # Nesne üretildiği saniye bu fonksiyon kendiliğinden çalışır:
    def __init__(self, isim: str, fiyat: int):
        self.isim = isim
        self.fiyat = fiyat
        self.stokta_var_mi = True  # Her yeni ürün otomatik stokta başlar

# Kullanımı:
yeni_urun = Urun("Oyuncu Mouse", 800)

5. Metotlar ve Kapsülleme (Encapsulation)

OOP'nin en büyük gücü: Veri ve o veriyi işleyen fonksiyonları aynı kutuya koymaktır.

❌ Eski / Kötü Yol (Fonksiyonel Dağınıklık):

urun = {"isim": "Laptop", "fiyat": 20000}

# Dosyanın bambaşka bir yerinde:
def kdv_hesapla(fiyat):
    return fiyat * 1.20

def indirim_yap(fiyat, oran):
    return fiyat - (fiyat * oran / 100)

✅ Modern OOP Yolu (Kapsülleme):

Hesaplamaları doğrudan Urun sınıfının içine birer metot olarak ekleriz:

class Urun:
    def __init__(self, isim: str, fiyat: int):
        self.isim = isim
        self.fiyat = fiyat

    # Ürünün kendi KDV'sini hesaplayan metodu:
    def kdv_dahil_fiyat(self) -> float:
        return self.fiyat * 1.20

    # Ürüne indirim uygulayan metot:
    def indirim_uygula(self, yuzde: int):
        indirim_tutari = (self.fiyat * yuzde) / 100
        self.fiyat -= int(indirim_tutari)

# Kullanım:
laptop = Urun("Laptop", 20000)
print(laptop.kdv_dahil_fiyat())  # 24000.0 döner

laptop.indirim_uygula(10)        # %10 indirim uygula
print(laptop.fiyat)              # 18000 döner

6. Kalıtım (Inheritance / Miras Alma) Nedir?

Biyolojide anne ve babanızdan genetik özellikleri miras alırsınız; sıfırdan bir insan tasarlanmaz.

Yazılımda da bir sınıf, başka bir sınıfın tüm özelliklerini ve yeteneklerini miras alabilir.

SQLModel (Ata Sınıf)
Veritabanı Motoru + JSON Çevirici + Doğrulama
⬇️ Miras Alır (Inherits)
class Urun(SQLModel, table=True)
Bizim Ürün Tablomuz 
from sqlmodel import SQLModel, Field

# Urun sınıfı, SQLModel sınıfından miras alıyor:
class Urun(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    isim: str
    fiyat: int
    stokta_var_mi: bool = True
Neden Miras Aldık?
Eğer (SQLModel) yazmasaydık SQLite tablosu oluşturmak, JSON dönüşümleri yapmak ve veri doğrulamak için yüzlerce satır kod yazmamız gerekirdi. Miras aldığımız için tüm bu yetenekler tek kelimeyle sınıfımıza geçti!

7. FastAPI ve Backend Mimarisinde OOP

Backend projelerinde OOP şu 3 temel katmanda kullanılır:

1. Model ve DTO Kalıtım Hiyerarşisi

Kullanıcı yeni ürün eklerken ID yollamaz, ancak veritabanında ID olmalıdır. Bunu kalıtımla çok temiz çözeriz:

# 1. Ortak Ata Sınıf (Base)
class UrunBase(SQLModel):
    isim: str
    fiyat: int
    stokta_var_mi: bool = True

# 2. Kullanıcıdan veri alırken (ID yok):
class UrunCreate(UrunBase):
    pass

# 3. Veritabanı Tablosu (ID var):
class Urun(UrunBase, table=True):
    id: int | None = Field(default=None, primary_key=True)

2. Servis Katmanı (Service Pattern)

Endpoint fonksiyonlarının içine veritabanı sorgularını yığmak yerine, tüm işlemleri bir Servis Sınıfına devrederiz:

class UrunServisi:
    def __init__(self, session: Session):
        self.session = session  # Veritabanı oturumunu saklar

    def tumunu_getir(self):
        return self.session.exec(select(Urun)).all()

    def id_ile_getir(self, urun_id: int):
        return self.session.get(Urun, urun_id)
